# Architecture Decision Records

`docs/008_ADR_Index.md` is the **canonical** ADR index. This directory
transcribes each ADR from it into its own file so decisions can be linked to
individually and reviewed as discrete units. `docs/Architecture_001_...md`
§42 predates document 008 and is **superseded** by it wherever the two
disagree; document 001 §42 is not edited by this ticket (that is a later
documentation ticket's acceptance criterion).
