## Context

The frame mismatch is the subtle trap here: our frames are of-date, Horizons VECTORS are J2000, and a naive comparison introduces ~0.3–0.4°/century of precession error — one to two orders of magnitude above the 1–2 arcminute target. The answered questions resolved it by rotating our result into J2000 inside the harness only, using a full IAU 1976 ecliptic precession matrix rather than Schlyter's longitude-only term, because the latter's plane residual is itself arcminute-scale per century. 005 §8 wants validation authored independently of the implementation.

## Task

Build the validation harness in the astronomy package's test/validation tree: fixture loading, the harness-only IAU 1976 ecliptic precession matrix and fixed J2000 obliquity, ecliptic↔equatorial conversion for comparison against Horizons vectors, the angular/distance/Cartesian error metrics from 006 §8–10, per-body metric selection, and error statistics reporting. Quantify and document the harness's own rotation residual. Do not adjust any model to make numbers look better — this task only measures.
