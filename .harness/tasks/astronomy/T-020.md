## Context

The answered questions deliberately refused to invent tolerance numbers: they are derived empirically in this first validation run and frozen as baselines, accepting whatever the model achieves. ADR-020 and 006 §22 forbid inferring accuracy from a handful of dates, hence the ~2400-point sweep for derivation and the 100-date committed subset for CI. 005 §9 forbids weakening a failing test to get a green build — a body that misses the target is reported honestly.

## Task

Run the full validation sweep, derive per-body warning and failure tolerances, freeze them as committed regression baselines, and wire the 100-date CI subset into the mandatory CI gates. Write the validation reports into docs/validation with full provenance and honest interpretation, including the geometric-only and Earth-centre limitations. Update the registry's accuracy metadata from measured results. Do not modify any model equation or constant in this task; if a body fails badly, report it and raise a follow-up.

## Acceptance criteria

- [ ] The full 30-day sweep (~2400 instants per body across 1900–2100) is run and its per-body error statistics recorded
- [ ] Per-body warning and failure tolerances are derived from that run and committed as data attached to the model (e.g. per model ID, per body), with no single universal tolerance shared across all bodies
- [ ] A regression test suite runs the committed 100-date CI subset for every body and fails when any body exceeds its frozen failure tolerance; this suite is a mandatory CI gate
- [ ] Tolerances are expressed on the headline geometric geocentric angular metric, with EARTH on heliocentric angular plus distance as established by the harness
- [ ] docs/validation contains a report per model stating: model, date range, bodies, frames, reference source and its exact Horizons configuration, sample size, mean/median/95th percentile/maximum error, worst-case date per body, known failures and interpretation
- [ ] The report explicitly states that V1 positions are geometric — no light-time, aberration or nutation — and that they are compared against Horizons geometric vectors
- [ ] The report quantifies the Earth-centre vs Earth–Moon-barycentre ambiguity as a known limitation with its estimated angular contribution per body
- [ ] Any body whose achieved accuracy falls materially outside the 1–2 arcminute engineering target is reported as such rather than having its tolerance quietly widened; no model constant is tuned to fit a fixture
- [ ] Model accuracy metadata in the registry is updated with the measured expectedAngularAccuracy and validated: true only for bodies whose fixtures pass
