## Context

These are the contracts every planetary/lunar model and the API serializer depend on, so defining them once here avoids each model task inventing its own shape. The answered questions moved modelId onto each body entry because a single response can mix SCHLYTER_PLANETS_V1, SCHLYTER_MOON_V1 and SCHLYTER_PLUTO_V1. V1 emits no velocity, so the field exists but stays undefined.

## Task

Define the astronomy domain's core typed structures, the error contracts from 002 §21, and the engine and per-body-model interfaces. Document units for every field. Provide no body models and no computation here — this task establishes the shapes that the phase-2 model tasks fill in.
