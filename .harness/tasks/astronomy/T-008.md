## Context

002 §19 requires physical metadata to be kept strictly separate from calculated state. The answered questions narrowed body orientation to constant pole plus constant rotation rate with an absolute prime-meridian phase W0 so Earth's sub-solar point is physically correct, sourced from IAU WGCCRE 2015; the renderer derives spin client-side from this metadata, so it must be complete and shipped via GET /api/v1/bodies. Textures are the CC-BY Solar System Scope set.

## Task

Build the typed body registry in packages/astronomy/src/bodies with full metadata for the eleven V1 bodies, including the IAU-style orientation constants and the asset identifiers the renderer will use. Cite every constant. Record the texture attributions in THIRD_PARTY_ASSETS. Keep algorithms out of this module entirely.

## Acceptance criteria

- [ ] The registry contains exactly the eleven V1 bodies and exposes them in a documented canonical order
- [ ] Each entry carries: id, displayName, type (STAR | PLANET | DWARF_PLANET | MOON), parentBody, radius {value, unit}, mass {value, unit}, supportedFrames, modelId, accuracy metadata, supportedDateRange, and a texture/asset identifier
- [ ] Orientation metadata per body uses the IAU form { poleRightAscensionDeg, poleDeclinationDeg, primeMeridianW0Deg, rotationRateDegPerDay, epochJulianDate } expressed in the J2000 equatorial frame
- [ ] Every physical constant and every orientation constant cites its source; orientation constants cite the IAU WGCCRE 2015 report and radii/masses cite a named source with retrieval date, recorded in a references document
- [ ] All eleven bodies list all three V1 frames as supported (degenerate combinations are handled by the engine, not excluded here)
- [ ] Pluto is present as type DWARF_PLANET with modelId SCHLYTER_PLUTO_V1 and its own documented 1800–2100 model validity window, narrowed by the project range to 1900–2100
- [ ] modelId assignment matches the fixed registry: SCHLYTER_SUN_EARTH_V1 for SUN and EARTH, SCHLYTER_PLANETS_V1 for MERCURY through NEPTUNE, SCHLYTER_MOON_V1 for MOON, SCHLYTER_PLUTO_V1 for PLUTO
- [ ] The registry contains no positional calculation and imports no model code; a test asserts metadata is immutable at runtime
- [ ] Texture identifiers refer to the Solar System Scope CC-BY map set and the corresponding attribution entries are added to THIRD_PARTY_ASSETS
