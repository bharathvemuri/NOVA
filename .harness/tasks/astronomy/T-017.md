## Context

001 §66 uses this CLI as the proof that the scientific core works without React or Three.js — 'Verified Astronomy Core v0.1'. It was accepted into V1 scope as a thin bin with no new dependencies and a CI smoke test. It is deliberately not a full-featured tool.

## Task

Add a minimal CLI bin to packages/astronomy that resolves a single body/instant/frame through the engine and prints the result with explicit units and metadata. Handle the domain errors with clear messages and non-zero exit codes. Wire a smoke test into CI. Add no dependencies and no new capability beyond what the engine already exposes.

## Acceptance criteria

- [ ] `astronomy calculate --body mars --date "2026-08-14T22:00:00Z" --frame HELIOCENTRIC_ECLIPTIC` prints position, distance, spherical coordinates, frame, model ID and instant with explicit units
- [ ] The bin lives inside packages/astronomy and adds zero new runtime dependencies (argument parsing is hand-rolled or uses node:util parseArgs)
- [ ] Invalid body, invalid frame, malformed date and out-of-range date each print a clear error naming the domain error code and exit with a non-zero status
- [ ] The CLI imports nothing from React, Three.js or Express and runs under plain Node 20 with no browser environment
- [ ] A CI job runs at least one successful invocation and one failing invocation and asserts the exit codes and that expected substrings appear in the output
- [ ] Output format is documented in the package README
