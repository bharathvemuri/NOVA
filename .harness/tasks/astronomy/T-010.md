## Context

001 §69 makes Earth/Sun the first validated model deliberately, before expanding to other planets. 002 §13 warns against conflating the apparent solar orbit with a physical Sun state. The EMB question was answered in favour of treating the model output as Earth's centre with no correction, with the ambiguity quantified later in the validation report — so the limitation must be written down here, not silently absorbed.

## Task

Implement the Sun/Earth model on top of the elliptic pipeline, exposing Earth's heliocentric ecliptic state and the Sun's apparent geocentric state as distinct, clearly named outputs. Cite every equation. Reproduce the tutorial's worked example as a committed test. Document the Earth-centre-vs-EMB simplification as a known limitation. Do not add light-time, aberration or nutation corrections — V1 is geometric.

## Acceptance criteria

- [ ] The model exposes Earth heliocentric ecliptic position and, separately, the Sun's apparent geocentric ecliptic position; the two are never returned by the same accessor or under the same name
- [ ] No code path labels the apparent solar position as a physical barycentric Sun state; module documentation states this explicitly
- [ ] Model ID SCHLYTER_SUN_EARTH_V1 is attached to states produced by this model, and it serves both SUN and EARTH
- [ ] Results are reproduced against Schlyter's worked example date to the tutorial's own stated figures, with the comparison committed as a test
- [ ] The model output is documented as Earth's centre with no Earth–Moon-barycentre correction applied, and the ~4670 km EMB ambiguity is recorded as a known limitation in the module docs and in docs/astronomy
- [ ] Distance to the Sun in AU is returned and tested for plausibility across a year (perihelion ≈ 0.983 AU in early January, aphelion ≈ 1.017 AU in early July)
- [ ] Every equation cites its tutorial section; no undocumented constant appears
- [ ] Determinism test: repeated evaluation at the same instant yields identical output
