## Context

Time is foundational (001 §9) and must not be duplicated across body models. The answered questions fix V1 as UTC-only: the TimeScale enum exists but only UTC is implemented, JD(UTC) goes straight into the Schlyter equations, and the UT1/TT approximation is documented rather than corrected. The date range is a hard gate, not a warning — every entry point into the engine funnels through the same range check so the API can translate it to a 422.

## Task

Implement packages/astronomy/src/time: the AstronomicalInstant type, Gregorian calendar ↔ Julian Date conversion preserving fractional days, instant parsing from strict ISO-8601, the supported-range guard, and the Schlyter day-number derivation as a named model quantity. Document the precision characteristics and the deliberate UTC-only simplification. Do not implement leap seconds, delta-T, or sidereal time.
