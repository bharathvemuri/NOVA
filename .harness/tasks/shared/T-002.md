## Context

This is the contract task that both the astronomy package and the API/web layers build against, so it is deliberately early and several later tasks depend on it. 003 §8 says the JSON schema should be generated from shared TypeScript contracts and runtime validation schemas, and 003 §15 says compile-time types are insufficient at the HTTP boundary — hence Zod in shared. Per the answered questions, modelId is per-body (there is no top-level model field on the response), spherical angles are degrees everywhere including RA, and V1 emits no velocity.

## Task

Define the shared vocabulary of the system in packages/shared: body identifiers and their canonical order, reference frames, time scales, model IDs, unit-tagged quantity types (position vector in AU, distance in AU, ecliptic longitude/latitude in degrees, right ascension/declination in degrees), the ephemeris and batch request/response shapes, and the structured error envelope from 003 §13. Express the request/response contracts as Zod schemas and derive the TypeScript types from them so there is a single source of truth. Include no algorithms — this package is types, constants and schemas only.
