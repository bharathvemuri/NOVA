## Context

004 §16 required transitions to be smooth, interruptible, non-teleporting and safe across frame changes but named no durations or distances; the answered questions fixed 6× display radius, 800 ms ease-in-out, click-selects/double-click-focuses, tracking as a separate toggle holding a constant scene offset, and the frame-switch and mode-switch behaviours. The 'safe when target disappears' requirement matters because prefetch failures can pause mid-transition.

## Task

Implement the three camera modes as an independent camera controller: free orbit/pan/zoom, focus with the fixed settle distance and interruptible 800 ms transition, and tracking with a constant scene-space offset and its gesture rules. Handle frame switches, mode switches (with radius tweening), reset/home, and unavailable-target safety. Ensure the controller only reads astronomical state.

## Acceptance criteria

- [ ] Focus is an explicit action (double-click on a body or a panel button), separate from selection
- [ ] Focus settles at 6× the body's current display radius, clamped to the [0.05, 20000] zoom bounds, over an 800 ms ease-in-out transition
- [ ] Focus transitions are interruptible: a new focus, a user drag, or a pause mid-transition takes effect immediately without teleporting
- [ ] Tracking is a separate toggle, not an automatic promotion from focus
- [ ] While tracking, the camera holds a constant scene-space offset from the body so the body stays centred and the background sweeps past
- [ ] Orbit and zoom gestures during tracking adjust the tracking offset and do not break tracking; panning exits to free mode
- [ ] Selecting a different body while tracking retargets tracking to the new body
- [ ] Switching reference frame while focused or tracking keeps the same body focused/tracked and re-derives its scene position; the camera does not reset to home
- [ ] Switching rendering mode while focused or tracking re-settles the camera to the new 6× display radius over the same 800 ms ease, and mesh radii tween over the same interval
- [ ] A reset/home action returns to the default view framing Neptune's orbit from any mode
- [ ] A test asserts the camera never writes to any astronomy state or scene body position
- [ ] Camera behaviour is safe when the tracked body's state is momentarily unavailable (e.g. during a refetch): the camera holds its last valid target rather than jumping to the origin
