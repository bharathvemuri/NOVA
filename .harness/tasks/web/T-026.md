## Context

Three earlier answers pointed in different directions; the final resolution is that the server computes everything through a single batch path and the browser only interpolates. The 0.45-day spacing is set by the Moon (27.3-day period at ≥60 samples/orbit), and the 1 month/sec rate cap exists precisely so a 500-instant window at 0.45-day spacing remains fetchable. The earlier 10 Hz recompute cadence is retired by the fixed spacing rule.

## Task

Implement the web app's astronomy service layer: typed wrappers over GET /bodies, GET /ephemeris and POST /ephemeris/batch; the rolling prefetch window with its fixed size, spacing and refetch threshold; window invalidation on rate/direction/jump changes; linear interpolation between samples; and the retry/timeout/pause failure policy emitting typed errors. Validate every response against the shared schemas. Do not import the astronomy package into the browser bundle.
