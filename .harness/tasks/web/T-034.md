## Context

The answered questions kept the timeline deliberately simple: a full-range scrubber plus a date-picker, requests on release only, no event markers. The 1 year/sec preset was dropped because at 0.45-day sample spacing it would exceed the 500-instant batch window. UI timezone is display-only — the wire format always carries an explicit offset per 003 §7.

## Task

Build the time control UI and the timeline scrubber wired to the simulation clock: playback transport, the surviving speed presets with an explicit rate label, the full-range scrubber applying on release, a validated date-picker, the display-timezone selector, and boundary clamp/auto-pause feedback. Ensure every clock-changing action invalidates the prefetch window. Avoid per-frame React re-renders of the tree.
