## Context

Full URL state was chosen specifically so the Playwright E2E suite can pin a deterministic instant despite the 'current browser time' default, and so links are shareable. replaceState with a 1 Hz throttle during playback is the fixed cadence — continuous updates at the interpolation rate would flood history.

## Task

Implement bidirectional URL state synchronisation for instant, frame, selected body and rendering mode: parse and validate on load with documented fallbacks, write the resolved default instant on first load, and update via throttled replaceState with immediate writes on discrete user actions. Add tests that pin state from a URL.

## Acceptance criteria

- [ ] Query parameters encode instant (ISO-8601 with explicit offset), frame, selected body and rendering mode, with documented names and validation
- [ ] On first load, the resolved default instant (browser 'now' at load) is written into the URL so a shared link is reproducible for the recipient
- [ ] Loading a URL with all parameters present reproduces exactly that application state, including the paused/selected/mode configuration
- [ ] URL updates use history.replaceState only — never pushState — so the browser back button is not flooded
- [ ] Updates are throttled to approximately 1 Hz while playing and applied immediately on pause, date jump, frame switch, mode switch and selection change
- [ ] Invalid or unknown parameter values fall back to the documented default and surface a non-blocking notice rather than crashing or silently mis-rendering
- [ ] An out-of-range instant in the URL shows the range error and falls back to the default instant
- [ ] A test navigates to a pinned URL and asserts the resulting store state deterministically
