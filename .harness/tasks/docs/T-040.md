## Context

007 §16 and ADR-020 set the quality bar: documented accuracy, documented limitations, no unexplained validation failure, clean onboarding. 001 §63 explicitly forbids exaggerated claims, and the answered questions require the README to say 'geometric' out loud so it does not imply sky-position accuracy the engine does not deliver. The ADR numbering conflict between 001 §42 and 008 was resolved in favour of 008.

## Task

Write the project documentation set: the README in the 001 §64 structure with honest measured accuracy claims, the astronomy documentation covering conventions, models, sources and the full known-limitations list, the references and asset attribution documents, and the onboarding instructions. Reconcile the ADR numbering by editing 001 §42 to defer to Document 008. Verify the onboarding instructions by following them from a clean checkout.

- [ ] README follows the 001 §64 structure and states what the project does, how positions are calculated, how accuracy is validated, how the renderer works, and how AI agents were constrained
- [ ] Accuracy claims in the README cite the measured validation results with model, date range, frame, metric and sample size — and explicitly state that positions are geometric, that light-time and aberration are not applied, and that the figures are not a claim of professional ephemeris accuracy
- [ ] Document 001 §42's ADR list is edited to defer to Document 008 as canonical rather than listing conflicting numbers, and a note records the supersession
- [ ] docs/astronomy documents the time scales used, the coordinate conventions, the exact astronomy→scene axis mapping, the model equations and their sources, the supported date range, and every known limitation (geometric-only, UTC-fed models, Earth-centre vs EMB, constant pole/no libration, no topocentric correction, Schlyter precession being longitude-only)
- [ ] docs/validation contains the per-model reports and is linked from the README
- [ ] A scientific references document lists Schlyter's tutorial, JPL Horizons, NASA/JPL NAIF SPICE and the sources for physical constants, orientation constants and textures with licenses
