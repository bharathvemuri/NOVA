## Context

003 §12 deferred this endpoint, but the answered questions pulled it into V1 because orbit paths are generated server-side (360 samples per body) and playback prefetches rolling windows of instants — both need it. The columnar shape was chosen specifically to keep 500-instant payloads small. Fail-fast was chosen over per-cell error entries to keep the contract simple.

## Task

Implement the batch ephemeris endpoint with the fixed request shape, cross-product evaluation, the 500-instant cap returning 413, the columnar response format, guaranteed ordering, and fail-fast validation before computation. Document the columnar schema in the shared package so the client can consume it type-safely. Measure and record worst-case latency; do not add caching.

## Acceptance criteria

- [ ] Request body shape is { frame, bodies, instants } validated by a Zod schema; instants is an explicit list (no range/step shorthand, no 'generate everything' form)
- [ ] The endpoint evaluates the full cross-product of bodies × instants
- [ ] More than 500 instants returns 413 with TOO_MANY_INSTANTS and the limit in details
- [ ] The response is columnar: a shared header (frame, per-body modelId, echoed instants) plus parallel per-body arrays of positions/distances/spherical coordinates, rather than repeating the full per-instant envelope
- [ ] Response ordering is guaranteed: instants in request order, bodies in canonical registry order; asserted by test
- [ ] Fail-fast semantics: any out-of-range instant returns 422 for the whole request and any unknown/duplicate/empty body returns 400 for the whole request, both before any computation begins
- [ ] A Kepler convergence failure mid-batch returns 500 NUMERICAL_CONVERGENCE_FAILURE for the whole request; no partial result is emitted
- [ ] Same-request determinism test passes on a 500-instant request
- [ ] A performance test records the wall time for a worst-case request (11 bodies × 500 instants) and the number is recorded in the API docs; no caching is added
- [ ] Unit presence is asserted for every quantity in the columnar payload
