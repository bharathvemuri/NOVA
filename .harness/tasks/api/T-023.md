## Context

This is the primary read path for the whole application. The answered questions settled every ambiguous parameter case (omitted vs empty vs duplicate bodies, case sensitivity, ordering) and the degenerate origin-body serialization (omit sphericalCoordinates — JSON cannot carry NaN). Per-body modelId is required because one response can span four model IDs.

## Task

Implement the ephemeris endpoint: strict Zod query validation, normalization into AstronomicalInstant, a controller that calls the astronomy engine (never computes), and a serializer that produces the fixed response contract with explicit units, frames and per-body model IDs. Cover the complete 003 §21 test list plus the determinism and origin-body cases.
