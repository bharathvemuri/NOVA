## Context

This is the first harness task (H001) and is intentionally narrow: foundation only. The toolchain is fixed by the answered questions: pnpm workspaces + TypeScript project references + Vitest + Vite + Playwright + Zod + GitHub Actions, targeting Node 20 LTS and current desktop Chrome/Firefox/Safari. ADR-001/002/003 make package boundaries load-bearing, so the boundary enforcement is part of the deliverable, not a nicety. Document 008 is the canonical ADR numbering (001 §42 is superseded).

## Task

Create the workspace-based monorepo described in 001 §6 with the fixed toolchain. Wire up strict TypeScript with project references so packages build independently, configure ESLint + Prettier, Vitest for unit tests, Vite for the web app, and Playwright for E2E. Add a GitHub Actions workflow running the CI gates required by 006 §23 (typecheck, lint, unit tests) with hooks for the domain/API test stages added later. Add a mechanised dependency-boundary check so that a future agent cannot import Three.js or React into packages/astronomy without failing CI. Seed the docs tree, the ADR index, the MIT LICENSE and the THIRD_PARTY_ASSETS ledger. Implement no product features.
